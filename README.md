# Intro

This repo is dedicated to creating decent `AGENTS.md` files.

`AGENTS.md` is loaded on every single session.

Every single hour you spend improving this file is priceless.

Do work on it every single week; the cycle goes like this:

1. Try things.
2. Break things.
3. Fix things.
4. Polish things.
5. Repeat from step 1

---
